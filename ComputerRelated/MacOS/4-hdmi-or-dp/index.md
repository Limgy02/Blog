# Mac mini 显示器连接 HDMI 还是 DisplayPort

创建于 2026/07/30；编辑于 2026/07/30

---

使用 HDMI 的好处非常显而易见，可以少用一个 Type-C 口，如果要插很多东西优势很明显，但很多时候多接一个扩展坞也并非不能接受。

而缺点是最近才发现的，使用 HDMI 连接 Mac mini 和显示器会导致屏幕点亮特别慢，我的显示器是创维的 F27G10U，经过测试的结果如下：

|设备|线材类型|按电源唤醒➡️显示器指示灯变白（秒）|显示器指示灯变白➡️显示器点亮（秒）|总时间（秒）|
|-|-|-|-|-|
|Mac mini|HDMI|5.0|2.84|7.84|
|Windows 笔记本|HDMI|2.71|2.86|5.57|
|Mac mini|TypeC 转 DP|1.49|2.93|4.42|

使用 Type-C 转 DP 线缆比双 HDMI 线缆的亮屏时间将近缩短了一倍，这是非常巨大的差距；可以说我之前都要被近 8 秒的亮屏时间逼疯换显示器，但目前看来不需要多花钱了。

此外可以发现，从显示器指示灯变白到显示器点亮的时间几乎是一致的，这应当是显示器硬件接到信号到点亮屏幕的固定时间。

> 此外据说使用支持 Type-C DP Alt-Mode 输入的显示器，会比转 DP 接口更快，这个我没有相应的显示器就无法测试了。

## 结论

除非一个 Type-C 口都腾不出来的情况，否则一律推荐使用 DisplayPort 链接显示器。
